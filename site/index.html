How it works

Nothing to open. Nothing to trust.

The Mac dials out to a small relay, and so does your phone. The relay joins the two and forwards bytes it can't read. Your Mac needs no port forwarding, VPN or fixed address.

Get started

Three minutes, start to finish.

You need a Mac with Homebrew, and Claude Code or Copilot CLI if you want the AI sessions.

Install the app

Download the APK on your Android phone and open it. Allow your browser to install apps when Android asks. It shows up as Mac Remote.

Install the agent on your Mac

In Terminal, run:

$ brew install babakzarrinbal/macremote/macremote $ macremote setup your.server:8460

Use the address of your relay. setup shows the relay's certificate pin to compare with the server, then starts the agent now and at every login.

Scan and go

setup ends with a QR code. In the app, tap Pair and scan it. To add more phones later, run macremote pair.

Keep it running

setup already runs the agent as a background service. It restarts if it ever stops, and starts again each time you log in, including after a reboot. Closing Terminal doesn't stop it. To check it, or to start it by hand:

# is it running? (macremote: started) $ brew services list | grep macremote $ macremote status # start it now and at every login $ brew services start macremote

To keep the Mac awake with the lid closed, so your agents keep working in your bag, run this (or flip the switch in the app's Mac sheet):

# stay awake with the lid closed (1 = on, 0 = back to normal) $ sudo pmset -a disablesleep 1

The log is in $(brew --prefix)/var/log/macremote.log. If FileVault is on, a rebooted Mac waits for you to log in once, and the agent starts then.

Questions

Good to know

Can the relay see my code or my prompts?

No. The phone and the Mac set up a Noise IK channel with keys made on each device. The relay only sees which room is connected, from which IP address, and how many bytes pass. Each side checks the other's key, so the relay can't pretend to be your Mac.

Can I run my own relay?

Yes. It's one small Docker container on any server with an open port. Run macremote setup your.server:8460 and the app follows, because the pairing code tells it where to connect.

What happens when I close the app?

Your sessions keep running on the Mac. A session that was idle releases its conversation, so your laptop can take over, and it starts again when you come back to it.

Is there an iPhone app?

Not yet. Android only for now.

Does it work with the lid closed on battery?

macOS normally sleeps when you close the lid. The switch in the app's Mac sheet turns that off (and back on). Keep an eye on the battery, which the same sheet shows.
